Free llms.txt Generator:
Template & Guide

📅 June 11, 2026✍️ Scanliq Team⏱️ 6 min read

One of the easiest ways to make your site AI-ready is adding an llms.txt file. In this guide you'll find ready-to-use llms.txt templates you can copy, plus step-by-step instructions to create and upload the file. No coding required.

What is llms.txt? A simple text file placed in your site's root directory that tells AI systems like ChatGPT and Claude about your site. For details, see our what is llms.txt guide.

llms.txt Template — Copy and Use

Copy the template below, replace it with your own site info, and save it as llms.txt.

Basic Template (Small Sites)

llms.txt — Basic
# llms.txt

## About This Site
[Your site name] — [describe what your site does in one sentence]

## Important Pages
- Home: https://yoursite.com/
- About: https://yoursite.com/about
- Contact: https://yoursite.com/contact

## Permissions
AI systems may read and summarize this site's content.

## Contact
Email: info@yoursite.com

Advanced Template (Business / Blog Sites)

llms.txt — Advanced
# llms.txt

## Company
Name: [Company Name]
Description: [Short description]
URL: https://yoursite.com
Language: en

## Content Categories
- [Category 1 — e.g. Blog posts]
- [Category 2 — e.g. Product pages]
- [Category 3 — e.g. Guides]

## Important Pages
- Blog: https://yoursite.com/blog
- Products: https://yoursite.com/products

## Preferences
Summarization: allowed
Training: disallowed
Commercial-use: contact-required

## Contact
Email: info@yoursite.com

How to Upload llms.txt — 3 Steps

1. Create the File

Open Notepad on your computer, paste the template, edit it with your info, and save it as llms.txt. Important: the extension must be .txt, not .txt.txt.

2. Upload to Root Directory

Upload the file to your site's main (root) directory — where your index.html lives. Use your hosting file manager or FTP.

3. Test It

Open https://yoursite.com/llms.txt in your browser. If the file content appears, it's uploaded successfully.

Tip: If you use GitHub Pages, simply add the llms.txt file to your repo's root directory and commit it.

Frequently Asked Questions

Is the llms.txt file free?
Yes, completely free. You just create a text file and upload it to your site — no tools or subscriptions needed.
Where is llms.txt uploaded?
To your site's root directory, accessible at https://yoursite.com/llms.txt.
How often should I update llms.txt?
Update it when you add important new sections to your site. Reviewing it every few months is good practice.
