Ghost Pages in AI: Is JavaScript Hiding Your Content?

📅 June 28, 2026✍️ Scanliq Team⏱️ 7 min read

You open your site in a browser, everything shows — products, text, headings. But when AI looks at your site, it might see a completely empty page. This is the most insidious AI visibility problem of the modern web: content loaded via JavaScript. This guide explains the "ghost page" problem and whether your site is actually being read by AI.

The core problem: Many modern sites load content later via JavaScript. A human browser runs it and sees the content. But some AI bots don't run JavaScript — for them, the page is empty.

What is the Ghost Page Problem?

A web page can deliver content two ways: server-side as ready HTML, or client-side later via JavaScript. A human browser sees both. But most AI bots only read raw HTML — they don't run JavaScript. So if your content loads via JS, it's invisible to AI.

Test How Your Site Looks to AI

1. Disable JavaScript

Temporarily disable JavaScript in your browser and open your page. Do you still see content? If not, AI bots might not either.

2. View Page Source

Right-click → "View Page Source." The raw HTML you see here is what AI bots see. If your text isn't here, there's a problem.

Solution: Content AI Bots Can Read

SSR or Static Render

Render your content server-side (SSR) or serve it as static HTML. That way content is ready in raw HTML and AI bots read it.

Keep Critical Content in HTML

At minimum, the title, description, main text and structured data (JSON-LD) should be directly in HTML — not dependent on JavaScript.

Add Structured Data Statically

Embed your JSON-LD blocks statically in the page source. See our Schema.org guide.

Why is This Critical for E-commerce and SPAs?

Single-page applications (SPAs) built with frameworks like React and Vue, and many e-commerce platforms, load content via JS. These sites look great but are dangerous for AI. We touched on this in our e-commerce GEO guide. First solidify your GEO fundamentals.

Frequently Asked Questions

Do AI bots run JavaScript?
Most AI bots don't run JavaScript, they only read raw HTML. So content loaded via JS may be invisible to AI.
How do I test how my site looks to AI?
Disable JavaScript in your browser or inspect the raw HTML via 'View Page Source.' If your text isn't there, AI can't see it either.
What should I do if I use an SPA?
Use server-side rendering (SSR) or static HTML. At minimum keep critical content and JSON-LD directly in HTML.
